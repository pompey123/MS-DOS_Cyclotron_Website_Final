PRELIMINARY DESIGN REVIEW (PDR)

1. System Architecture

Our satellite is programmed in a patch of ASM CORTEX, C++ and C. There is the possibility of using hardware translators.

CPU RP2350 Dual-Core @ 150 MHz

I2C BMP280 (Address 0x76)

SPI RFM95W LoRa (to be decided)

2. Hardware Wiring
Pico 2 Pin Target Device Target Pin Function
Pin 36 (3.3V) BMP280 / Transceiver VCC / VIN 3.3V Core Power Rail
Pin 38 (GND) BMP280 / Transceiver GND Common Ground
GP0 (I2C0 SDA) BMP280 Sensor SDA I2C
GP1 (I2C0 SCL) BMP280 Sensor SCL I2C
GP4 (SPI0 RX) RFM95W MISO SPI
GP7 (SPI0 TX) RFM95W MOSI SPI
GP6 (SPI0 SCK) RFM95W SCK SPI
3. Mechanical Layout & Recovery

The physical structure is partitioned into two distinct internal compartments:

  • The upper recovery bay houses the 15-inch Estes plastic parachute under a friction-fit top cap lid.
  • The lower avionics bay holds the Raspberry Pi Pico 2, LiPo power battery, and BMP280 sensor mounted centrally on vibration-isolated standoffs.
